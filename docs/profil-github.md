## Installation (2 minutes, dans le navigateur)

1. <https://github.com/new>
2. **Repository name** : `darelaholou4-ux` — exactement, sans majuscule, sans tiret en plus.
3. Visibilité : **Public**.
4. Cocher **Add a README file**, puis **Create repository**.
5. Ouvrir le `README.md`, cliquer sur le crayon, coller le texte ci-dessous, **Commit changes**.
